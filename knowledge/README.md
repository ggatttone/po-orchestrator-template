# Knowledge Base

This directory contains shared reference files used by all agents and skills. Customize these files to match your organisation, program, and systems.

## Customization priority

Start with these files (highest priority first):

| Priority | File | What to customize |
|---|---|---|
| 1 | `glossary.md` | Add your organisation's terms and abbreviations |
| 2 | `systems-landscape.md` | Describe your systems (ERP, CRM, WMS, planning tools) |
| 3 | `governance.md` | Map your governance layers and stakeholder groups |
| 4 | `jira-field-mapping.md` | Enter your Jira custom field IDs |
| 5 | `stakeholder-map.md` | Add your team members and roles |
| 6 | `way-of-working.md` | Adjust sprint cadence, stagegates, DoR/DoD |
| 7 | `calendar-config.md` | Add your Outlook/Google ICS calendar URL |
| 8 | `naming-conventions.md` | Document your Jira naming patterns |

## Files you can use as-is

These files are already generic and ready to use:

- `requirement-standards.md` — Section-per-requirement format, scenario extraction rules
- `learning-resources.md` — Supply chain, ERP, and PM learning resources
- `elicitation-question-bank.md` — Pre-written business elicitation questions

## Auto-generated files

These files are produced by agents — do not manually edit:

- `epic-timeline.md` — Auto-generated by `pm-support` when running `/priority-review all`
